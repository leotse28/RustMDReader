## 一、MD Reader 是什么

**一句话：它是一个"专门用来看 .md 文件"的软件，像用 Word 看文档一样，只不过它看的是一种叫 Markdown 的纯文字文件。**

### 它能用来做什么

| 你能做的事 | 说明 |
|---|---|
| 看 Markdown 文件 | 标题、表格、图片、代码都会自动排版得整整齐齐 |
| 看流程图 | 文件里写的流程图会自动画成图片 |
| 看数学公式 | 文件里写的公式会变成课本上那种排版 |
| 同时看多个文件 | 像浏览器一样开多个"标签页" |
| 搜索文字 | 按 Ctrl+F 查找，能告诉你在第几处 |
| 换深色/浅色 | 晚上看不刺眼 |
| 导出 PDF | 把文件变成 PDF，方便发给别人或打印 |
| 简单修改文件 | 内置编辑器，改完保存即可 |

### 它的几个特点

- **不用安装**：它是个"绿色软件"，复制到电脑上双击就能用，删除文件夹就等于卸载。
- **不用联网**：所有功能都在你电脑本地完成，文件不会上传到任何地方。
- **只支持 Windows**：Windows 10 和 Windows 11 可用。苹果电脑（macOS）和 Linux 暂时不能用。

## 二、第一次使用：5 步上手

如果你不想看长篇说明，只做这 5 步就能开始阅读：

1. 把别人给你的 **MD Reader 文件夹**整个复制到电脑上（例如 `D:\工具\MD Reader\`）。
2. 双击文件夹里的 **mdreader.exe**。
3. 如果弹出蓝色的"Windows 已保护你的电脑"窗口，点 **"更多信息"**，再点 **"仍要运行"**。
4. 把你要看的 **.md 文件用鼠标拖进窗口**（或者按 Ctrl+O 选择文件）。
5. 开始阅读。想换深色模式按 **Ctrl+D**，想放大字体按住 **Ctrl 滚动鼠标滚轮**。

## 三、如何获取与安装

### 3.1 你会拿到什么

MD Reader 有两种发放形式，拿到哪种都行：

| 形式 | 长什么样 | 说明 |
|---|---|---|
| 文件夹版（常见） | 一个文件夹，里面有 `mdreader.exe` 和一个 `web` 文件夹 | **`web` 文件夹必须和 exe 放在一起**，不能只拿走 exe |
| 单文件版 | 只有一个 `MDReader.exe` 文件 | 直接双击即可 |

> 如果同事只发给你一个 exe 而打不开，多半是漏了 `web` 文件夹——找对方要完整文件夹。

### 3.2 安装步骤（Windows 10 / 11）

MD Reader **不需要安装程序**，按下面做即可：

1. **选一个存放位置**。建议放在不会被误删的地方，例如：
   - `D:\工具\MD Reader\`
   - 或 U 盘里（可以随身携带，插到任何 Windows 电脑都能用）
2. **复制整个文件夹**到上面选好的位置。
3. **双击 `mdreader.exe`** 启动。
4. 第一次启动时可能出现以下两种情况：

   **情况 A：出现"Windows 已保护你的电脑"蓝色窗口**
   - 这是 Windows 对"来源不明的程序"的例行提醒，不是病毒提示。
   - 点窗口里的 **"更多信息"** → 点 **"仍要运行"**。
   - 之后一般不会再出现。

   **情况 B：提示缺少 "WebView2" 或窗口一片空白**
   - 说明你的电脑缺少 MD Reader 依赖的一个系统组件（微软的网页显示引擎）。
   - 解决办法：打开浏览器搜索 **"WebView2 Runtime 下载"**，进入微软官方网站（developer.microsoft.com 开头的地址），下载 **"Evergreen Bootstrapper"**，双击安装，装完重新打开 MD Reader 即可。
   - Windows 10/11 通常已经自带这个组件，只有少数精简版系统需要手动装。

5. **（可选）创建桌面快捷方式**：
   - 右键 `mdreader.exe` → **"发送到"** → **"桌面快捷方式"**。
   - 以后双击桌面图标就能打开。

### 3.3 如何卸载

直接**删除整个文件夹**即可，不留任何残留。（配置文件就放在文件夹里，一起删掉。）

### 3.4 让 .md 文件双击就用 MD Reader 打开（可选）

1. 在任意 `.md` 文件上**右键** → **"打开方式"** → **"选择其他应用"**。
2. 点 **"更多应用"** → 拉到最下面点 **"在这台电脑上查找其他应用"**。
3. 找到你存放的 `mdreader.exe`，选中。
4. 勾选 **"始终使用此应用打开 .md 文件"** → 确定。
5. 以后双击任何 `.md` 文件就会直接用 MD Reader 打开。

## 四、如何打开一个 Markdown 文件

有四种方法，任选一种：

### 方法 1：拖进来（最简单）

把 `.md` 文件**用鼠标拖到 MD Reader 窗口里**，松手即可打开。

### 方法 2：菜单打开

1. 点左上角菜单 **"文件"** → **"打开文件"**（或直接按 **Ctrl+O**）。
2. 在弹出的窗口里找到你的 `.md` 文件，双击它。

### 方法 3：打开整个文件夹

如果你的文件很多，可以一次打开整个文件夹：

1. 菜单 **"文件"** → **"打开文件夹"**（或按 **Ctrl+Shift+O**）。
2. 选择文件夹后，左侧会出现**文件列表**，点哪个文件就看哪个。

### 方法 4：双击文件（需先做 3.4 的设置）

设置过"默认打开方式"后，双击任何 `.md` 文件即可。

### 自己动手试一次

1. 在桌面空白处右键 → **"新建"** → **"文本文档"**。
2. 把文件名改成 `测试.md`（注意：要把结尾的 `.txt` 删掉，只留 `.md`）。
3. 双击打开它，把下面这段内容复制进去，保存并关闭：

   ```markdown
   # 我的第一个 Markdown 文件

   这是一段普通文字。**加粗**、*斜体*、`行内代码`。

   ## 一个小表格

   | 名称 | 数量 |
   |---|---|
   | 苹果 | 3 |
   | 香蕉 | 5 |

   > 这是一段引用文字。

   - 列表第一项
   - 列表第二项
   ```

4. 用 MD Reader 打开这个 `测试.md`，你会看到标题、表格、列表都自动排好了版。

## 五、界面各部分的作用

打开一个文件后，窗口从上到下、从左到右分为这些区域：

```
┌──────────────────────────────────────────────────┐
│ 菜单栏：文件  编辑  视图  帮助                      │
├──────────────────────────────────────────────────┤
│ 工具栏：[打开][文件夹][刷新] … [编辑][追踪][修订] … │
├──────────────────────────────────────────────────┤
│ 标签页： 文件A ×   文件B ×   ＋                    │
├──────────┬───────────────────────────────────────┤
│ 左侧栏    │                                       │
│ 文件/大纲 │           阅读区（正文）               │
│ /最近     │                                       │
│          │                                       │
├──────────┴───────────────────────────────────────┤
│ 状态栏：字数 · 行数 · 预计阅读时间                  │
└──────────────────────────────────────────────────┘
```

### 5.1 菜单栏

| 菜单 | 里面有什么 |
|---|---|
| **文件** | 打开、打开文件夹、新建、保存、另存为、关闭标签、退出 |
| **编辑** | 编辑/预览切换、追踪编辑、修订模式、查找、替换 |
| **视图** | 切换侧栏、文档大纲、切换主题、放大、缩小、重置缩放、重新加载、打印/导出 PDF |
| **帮助** | 快捷键设置、关于 MD Reader |

> 说明：**撤消（Ctrl+Z）**和**显示标记（Ctrl+Shift+M）**没有放进菜单，分别用快捷键和工具栏按钮操作。

### 5.2 工具栏按钮（从左到右）

| 按钮 | 作用 |
|---|---|
| 打开 | 打开一个文件（同 Ctrl+O） |
| 文件夹 | 打开一个文件夹（同 Ctrl+Shift+O） |
| 刷新 | 重新读取当前文件（文件被别处改过时用，同 F5） |
| 铅笔（编辑） | 进入编辑模式，左边改字、右边实时预览（同 Ctrl+E） |
| 追踪编辑 | 点一下正文里的某一段，弹出大窗口改这一段（同 Ctrl+Shift+E） |
| 修订模式 | 修改时保留"原文/新文"对比，可接受或拒绝（同 Ctrl+Shift+R） |
| 标记 | 显示/隐藏修订和批注的标记（同 Ctrl+Shift+M） |
| 侧栏 | 显示/隐藏左侧栏（同 Ctrl+B） |
| 大纲 | 打开左侧的"大纲"页（同 Ctrl+T） |
| 太阳/月亮 | 切换深色/浅色主题（同 Ctrl+D） |
| − 100% + | 缩小 / 当前缩放比例（点一下恢复 100%）/ 放大 |
| 打印机 | 导出 PDF（同 Ctrl+P） |

### 5.3 标签页

- 每打开一个文件就多一个"标签"，像浏览器一样。
- 点标签切换文件；点标签上的 **×** 关闭。
- **按住标签左右拖动可以调整顺序**。
- 关闭软件再打开，上次开着的文件会自动恢复。

### 5.4 左侧栏

左侧栏顶部有三个页签：

| 页签 | 内容 |
|---|---|
| **文件** | 打开文件夹后，这里显示文件夹里的所有文件，点一下就能看 |
| **大纲** | 自动列出文档里的所有标题，点一下直接跳到那一节 |
| **最近** | 你最近打开过的文件，点一下重新打开 |

### 5.5 阅读区

- 正文显示区域。用鼠标滚轮上下滚动。
- 点击图片可以全屏查看，按 **Esc** 退出全屏。
- 鼠标移到代码块上会出现 **"Copy"** 按钮，点一下复制代码。
- 流程图右下角有缩放按钮（− / + / 百分比 / ⟲ 复位），也可以按住拖动平移。

### 5.6 右侧批注栏（有修订或批注时才出现）

当文档里有"修订"或"批注"时，正文右边会出现一列卡片，显示修改建议和评论，可以点"接受/拒绝/解决/删除"。

### 5.7 状态栏（最底部）

显示当前文件的**字数、行数、预计阅读时间**，以及顶部的一条阅读进度条。

## 六、常用操作

### 6.1 阅读

- **滚动**：鼠标滚轮，或拖动右侧滚动条。
- **跳章节**：打开左侧"大纲"（Ctrl+T），点标题直接跳过去。
- **看大图**：点击正文里的图片，按 Esc 退出。
- **复制代码**：鼠标移到代码块，点右上角 "Copy"。

### 6.2 切换文件

| 想做的事 | 怎么做 |
|---|---|
| 切到另一个已打开的文件 | 点它的标签页 |
| 下一个 / 上一个标签 | Ctrl+Tab / Ctrl+Shift+Tab |
| 关闭当前文件 | Ctrl+W 或点标签上的 × |
| 打开新文件 | Ctrl+O，或拖文件进窗口 |

### 6.3 搜索文字

1. 按 **Ctrl+F**，窗口上方出现搜索框。
2. 输入要找的字，所有出现的地方会高亮，并显示"第几处/共几处"。
3. 按 **Enter** 跳到下一处，**Shift+Enter** 跳到上一处。
4. 按 **Esc** 关闭搜索框。

**替换文字**：按 **Ctrl+H**，多出一行"替换为"输入框，可以"替换"当前一处或"全部替换"。

### 6.4 调整显示

| 想做的事 | 怎么做 |
|---|---|
| 放大 / 缩小字体 | 按住 **Ctrl** 滚动鼠标滚轮；或 Ctrl+= / Ctrl+- |
| 恢复 100% | 按 **Ctrl+0**，或点工具栏的百分比数字 |
| 深色 / 浅色切换 | 按 **Ctrl+D**，或点工具栏的太阳/月亮图标 |
| 隐藏左侧栏（更宽） | 按 **Ctrl+B** |

> 主题和缩放比例会被记住，下次打开还是你上次的设置。

### 6.5 导出 PDF

按 **Ctrl+P**，稍等片刻会生成一个 PDF 文件并自动打开。适合发给别人或打印。

### 6.6 修改文件（进阶）

- **整篇修改**：按 **Ctrl+E** 进入编辑模式，左边改字、右边实时预览；改完按 **Ctrl+S** 保存。
- **只改一段**：按 **Ctrl+Shift+E** 进入追踪编辑，点正文里要改的那一段，在弹出的窗口里修改。窗口右上角可以调**编辑窗口大小**（− 45% +）和**文字大小**（A− 13px A＋）。
- **改错了想撤回**：按 **Ctrl+Z**，最多可以连续撤回 10 步。
- 有未保存的修改时，标签页上会出现一个 **●** 圆点；直接关闭会提醒你确认。

## 七、常见问题与排查

### 双击 mdreader.exe 没反应 / 一闪就没了

1. 确认 `web` 文件夹和 `mdreader.exe` 在**同一个文件夹里**（文件夹版必须这样）。
2. 右键 `mdreader.exe` → **"以管理员身份运行"** 试一次。
3. 如果被杀毒软件拦截，把 MD Reader 文件夹加入杀毒软件的**白名单/信任区**。
4. 换一个存放位置再试（例如从"下载"文件夹移到 `D:\工具\`，某些系统会限制"下载"目录里的程序运行）。

### 提示缺少 WebView2 / 窗口一片空白

你的电脑缺少微软的 WebView2 组件。搜索 **"WebView2 Runtime 下载"**，到微软官网下载安装后重开 MD Reader。详见 [3.2 第 4 步](#32-安装步骤windows-10--11)。

### 打开文件后中文是乱码

MD Reader 会自动识别常见编码（UTF-8、GBK 等），极少出错。如果仍乱码：

1. 用记事本打开该文件，**"另存为"** 时把编码选成 **UTF-8**，保存。
2. 回到 MD Reader 按 **F5** 重新加载。

### 图片显示不出来

- 图片文件和 `.md` 文件通常应放在**同一个文件夹**（或按文档里写的相对位置摆放）。
- 如果图片在别的电脑或网盘上，需要先把图片复制到本地。
- 检查文档里图片的写法，例如 `![说明](图片.png)` 中的文件名是否和实际文件一致（大小写也要一致）。

### 流程图 / 公式显示成了代码

说明这段流程图或公式的写法有错误，MD Reader 没看懂，就把原文显示出来了。常见原因：

- 流程图代码块开头必须是 ` ```mermaid `，公式要用 `$...$`（行内）或 `$$...$$`（单独一行）。
- 括号、花括号是否成对；命令拼写是否正确（如 `\binom`、`\underbrace`）。
- 改正后按 **F5** 重新加载。

### 搜索显示"找到 N 处"但看不到

- 如果命中的是**流程图源码**，MD Reader 会自动把那段源码展开给你看；跳走或关闭搜索框后会自动收回。
- 如果命中的内容在很长的文档深处，按 Enter 多跳几次，或看右侧滚动条位置。

### 保存失败 / 提示文件被占用

- 该文件可能正被别的程序（如 Word、网盘同步工具）打开，关掉那个程序再保存。
- 文件可能被设为"只读"，右键文件 → 属性 → 取消"只读"。
- 试试"另存为"（Ctrl+Shift+S）到别的位置。

### 界面乱了 / 设置改坏了想恢复默认

关闭 MD Reader，删除它文件夹里的 **`mdreader.config.json`** 文件，重新打开即可恢复默认设置（最近打开记录也会清空）。

### 软件会不会偷偷联网 / 上传我的文件

不会。MD Reader 完全离线运行，不联网、不上传任何内容。

## 八、术语解释（大白话）

| 术语 | 大白话解释 |
|---|---|
| **Markdown** | 一种"用纯文字写格式"的写法。比如在文字前面加 `#` 就变成大标题，加 `**` 就变粗体。写起来像记事本，看起来像排版好的文档。 |
| **.md 文件** | 用 Markdown 写法保存的文件，文件名以 `.md` 结尾。本质就是一个纯文字文件，用记事本也能打开（但只能看到符号，看不到排版）。 |
| **渲染** | 把"带符号的纯文字"变成"漂亮的排版"的过程。MD Reader 的核心工作就是渲染。 |
| **文件路径** | 文件在电脑里的"住址"，例如 `D:\资料\报告.md`。`D:\` 是盘符，`\` 表示"里面的"。 |
| **文件夹 / 目录** | 装文件的"抽屉"。目录和文件夹是同一个意思。 |
| **标签页** | 窗口顶部那一排"小书签"，每个代表一个打开的文件，点一下就切换。 |
| **代码块** | 文档里用三个反引号（```）围起来的一段内容，通常显示为灰底等宽字。流程图和代码都写在这种块里。 |
| **公式（LaTeX）** | 一种写数学公式的语法，用 `$` 符号包起来。MD Reader 会把它显示成课本里的公式样子。 |
| **流程图（Mermaid）** | 一种"用文字描述图形"的语法，写在 ` ```mermaid ` 代码块里，MD Reader 会自动画成图。 |
| **快捷键** | 键盘上的组合操作，比如 Ctrl+F 表示"按住 Ctrl 不放，再按 F"。比点菜单快。 |
| **纯文本** | 只有文字、没有隐藏格式的文件。`.md`、`.txt` 都是纯文本。 |
| **编码（UTF-8 / GBK）** | 电脑"记录文字"的方式。不同方式保存的中文，换一种方式读就可能变乱码。UTF-8 是最通用的。 |
| **PDF** | 一种"排版固定、在哪台电脑上看都一样"的文档格式，适合打印和发送。 |
| **绿色软件 / 便携版** | 不需要安装、复制到哪都能用的软件。删除文件夹就等于卸载。 |
| **WebView2** | 微软提供的"网页显示引擎"（Edge 浏览器同款内核）。MD Reader 用它来显示排版后的内容，Windows 10/11 一般自带。 |

## 九、快捷键速查表

| 快捷键 | 功能 |
|---|---|
| **Ctrl+O** | 打开文件 |
| **Ctrl+Shift+O** | 打开文件夹 |
| **Ctrl+N** | 新建文件 |
| **Ctrl+S** | 保存 |
| **Ctrl+Shift+S** | 另存为 |
| **Ctrl+F** | 查找 |
| **Ctrl+H** | 查找并替换 |
| **Ctrl+Z** | 撤消（最多 10 步） |
| **Ctrl+E** | 编辑 / 预览切换 |
